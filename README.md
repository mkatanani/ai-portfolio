# AI Portfolio

Small, working experiments by **Mark Katanani**, Principal Consultant, Salesforce and Business Operations at [Capability Methods](https://www.capabilitymethods.com).

I help owner-managed Florida businesses fix the operations problems that growth exposes. These projects are where I practice combining AI tools with process thinking. They are learning projects, built in the open, and they will change as I learn.

## Projects

| Project | What it does | Tools |
|---|---|---|
| [hello-claude](hello-claude) | A first, deliberately tiny call to the Claude API that prints an answer and the tokens used. It will not run without an explicit cost-approval flag. | Node.js, Anthropic SDK |

## Ground rules

- No client data, ever. Examples use sample or composite data and say so.
- No secrets in this repository. Keys live in a local `.env` file that Git ignores.
- Every project that can cost money says so in its README and needs an explicit flag to run.
