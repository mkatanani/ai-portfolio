# Process X-Ray: Quote to Cash

A 20-second animated map of a six-step business process. Numbered circles light up in order, a running clock adds up the days, and the one step that eats the most time turns red. It ends with a fix idea.

Everything is **sample data**. The example is a composite, not a real client.

## Open it

Double-click `index.html`. No install, no internet connection, and no cost.

- **Space bar**: restart the animation
- **Slider**: scrub through the timeline
- **`?t=8` on the end of the address**: freeze the page at 8 seconds, useful for a still image
- **`?record=1` on the end of the address**: hide the controls and fill the window, for screen recording

## Change the example

Open `index.html` and edit the `STEPS` list near the top of the script: each entry is a step name and a number of days. The red step is step 3. The text in the two cards at the bottom is plain text in the page.

## Built with

Plain HTML, CSS and JavaScript. The animation is driven by a single timeline, so any moment can be reproduced exactly.
